# 💫 About Me:
I'm a final-year computer science student with a passion for building robust and scalable backend systems. Over the past few years, I've developed strong expertise in NestJS, where I've built enterprise-grade applications using TypeScript, implementing clean architecture principles, dependency injection, and comprehensive API design.<br>My backend journey includes hands-on experience with RESTful APIs, GraphQL, database design with PostgreSQL and MongoDB, and implementing authentication systems using JWT and OAuth. I'm particularly drawn to NestJS's modular architecture and how it promotes maintainable, testable code through decorators, guards, and interceptors.<br>Beyond NestJS, I've worked with Docker for containerization, Redis for caching, and have experience with cloud deployment on AWS and Google Cloud Platform. I'm comfortable with Git workflows, unit testing with Jest, and have implemented CI/CD pipelines for automated deployments.<br>What excites me most about backend development is solving complex problems around data flow, system architecture, and performance optimization. I enjoy the challenge of designing APIs that are both powerful for developers and efficient at scale.<br>As I approach graduation, I'm eager to transition from academic projects to real-world applications where I can contribute to meaningful products while continuing to grow my technical skills. I'm particularly interested in opportunities where I can work on microservices architecture, distributed systems, and help teams build reliable, high-performance backend solutions.<br>When I'm not coding, I stay current with backend technologies through tech blogs, contribute to open-source projects, and enjoy collaborating with fellow developers on challenging problems.
